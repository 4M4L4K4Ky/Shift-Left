Leyenda
- Puertos: interfaces en `application.port.*` describen contratos.
- Casos de uso: `AnalyzeCodeUseCaseImpl` orquesta el flujo (IA → remediación → persistencia).
- Adaptadores: `in` expone la aplicación (REST/Web), `out` implementa los puertos hacia infra (IA, DB).
- Fichero PlantUML: `architecture.puml` (en este mismo directorio) para renderizar visualmente.

Cómo renderizar el PlantUML (si tienes plantuml y Java instalado):

```bash
# desde la raíz del proyecto
plantuml docs/architecture.puml -o docs
# o usar extension de tu editor (VSCode/IntelliJ) para previsualizar
```
